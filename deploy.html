Aturan kontrak (baca sebelum sign)

  • Nama: Cappybara — Symbol: CAPY (keduanya bisa diubah di Langkah 2 sebelum deploy; setelah deploy nama/symbol tidak bisa diubah).
  • Supply: 10.000 total — 5.000 Free (mintFree) + 5.000 Paid (mintPaid), alokasi terpisah. mintPaid tidak menunggu alokasi free habis.
  • ID token mengikuti fase situs: free = #1–5.000, paid = #5.001–10.000.
  • mintFree: fee 0.0001 BNB per token. mintPaid: harga 0.001 BNB per token. Keduanya diteruskan penuh ke treasury saat itu juga — fee tidak ditahan di kontrak. Harga BNB ini tetap (fixed): kontrak tidak memakai oracle harga, tidak memakai USDT, dan tidak memakai gate Binance Agent ID.
  • Treasury awal = wallet deployer, bisa diubah owner lewat setTreasury. withdraw() hanya katup pengaman untuk BNB yang nyasar ke kontrak; dalam pemakaian normal saldo kontrak 0.
  • Tidak ada gate Binance Agent ID di kontrak (situs hanya menampilkan status Agent ID; wallet agent dan wallet biasa sama-sama bisa mint). Tidak ada batas per wallet. Hanya wallet pribadi yang bisa mint (contract caller ditolak).
  • mintOpen default false — mint baru jalan setelah owner membukanya di Langkah 6.
  • tokenURI = baseURI + id token + ".json". BaseURI awal kosong, disetel owner di Langkah 5.
  • Mint yang sebenarnya terjadi di situs / lewat prompt agent, bukan dari halaman owner ini.

2. Deploy Kontrak Cappybara ERC-721

Kontrak ini memakai harga BNB tetap (mintFree 0.0001 BNB, mintPaid 0.001 BNB). Tidak ada input registry Agent ID, tidak ada input oracle harga, dan tidak ada input USDT — kontrak ini memang tidak punya ketiganya.

Data deploy manual (fallback): kalau tombol deploy gagal, salin data ini dan kirim sebagai transaksi manual (ke alamat kosong / contract creation, value 0 BNB) dari wallet yang mendukung kirim data mentah.

3. Alamat Kontrak Mint

Alamat ini terisi otomatis dari receipt deploy, atau isi manual kalau kamu sudah punya alamat kontraknya.

4. Trait & Metadata (Info Saja — Bukan Pengaturan On-Chain)

Kontrak ini tidak punya fungsi trait on-chain. Trait tidak disetel dari halaman ini dan tidak bisa diubah lewat kontrak. Trait setiap token sudah tetap di file metadata yang di-host, dan dibaca marketplace lewat tokenURI.

Tipe trait di metadata Cappybara (4 tipe):

  • Fur: Classic, Gold, Dark, Cream, Rust, Moss
  • Theme: Night Pool, Sunset, Forest, Purple Night, Stone Gray, Oasis
  • Accessory: No Accessory, Orange on Head, Bandana, Cherry Blossom, Fresh Leaf, Sunglasses, Golden Star, Golden Crown
  • Pose: Standing, Soaking

File metadata live di https://capyybara.fun/meta/N.json (N = id token), dan gambar di https://capyybara.fun/images/N.svg — fase free (#1–5.000) sudah lengkap; fase paid (#5.001–10.000) menyusul. Mengubah trait berarti mengubah file metadata yang di-host itu — bukan transaksi kontrak. Bagian ini hanya informasi, tidak ada tombol yang menulis trait ke chain.

5. Base URI

Status: metadata fase free (#1–5.000) sudah live di capyybara.fun (folder meta/), dan baseURI sudah disetel ke https://capyybara.fun/meta/ saat deploy — tokenURI token free sudah jalan. Metadata fase paid (#5.001–10.000) menyusul; karena baseURI-nya sama, tokenURI paid akan langsung jalan begitu file-nya live, tanpa perlu mengubah baseURI. TokenURI bersifat dinamis dan bisa diperbaiki kapan saja oleh owner.

6. Mint

Mint yang sebenarnya terjadi di situs / lewat prompt agent, bukan dari halaman owner ini. Halaman ini hanya membuka/menutup mint dan menampilkan counter live. Tidak ada tombol mint owner di sini.

7. Tarik Dana (BNB Saja)

Dalam pemakaian normal, fee mint langsung diteruskan ke treasury sehingga saldo kontrak 0. Tombol ini hanya untuk BNB yang nyasar ke kontrak: withdraw() milik owner mengirim seluruh saldo kontrak ke treasury, dan revert kalau saldo kosong. Kontrak ini tidak menangani USDT sama sekali — tidak ada fungsi tarik USDT.
