CAPPY Minter Registry Admin

This page registers the original minter wallet from NFT mint logs. Anyone may open this page, but only the registry owner can submit registrations. Each batch is sent as an on-chain transaction and requires the admin wallet's signature.

Important warning

The existing NFT contract does not register minters automatically. Audit every token ID and the mint recipient from the Transfer event before signing. Incorrect registration may grant the claim to the wrong address. Never enter a seed phrase or private key.

3. Review and register

Each batch can contain up to 100 NFTs. Check the count, block range, token IDs, minter addresses, and audit results before signing.
