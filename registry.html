Admin registry minter CAPPY

Halaman ini mendaftarkan wallet minter pertama dari log mint NFT. Pengguna lain dapat membuka halaman ini, tetapi hanya alamat owner registry yang boleh mengirim pendaftaran. Setiap batch dikirim sebagai transaksi on-chain dan memerlukan tanda tangan wallet admin.

Perhatian

Kontrak NFT lama tidak mendaftarkan minter secara otomatis. Audit setiap token ID dan alamat penerima mint dari event Transfer sebelum menandatangani. Pendaftaran yang salah dapat memberi hak klaim ke alamat yang keliru. Jangan masukkan seed phrase/private key.

1. Hubungkan owner registry

Belum terhubung. Klaim registry belum dideploy, jadi alamat kontrak harus dimasukkan setelah deployment.

2. Muat file batch registry

Gunakan file minter-registry.json yang dibuat oleh scripts/build_minter_registry.py. File harus berasal dari BNB Chain dan kontrak NFT Cappybara yang benar.

Belum ada file dimuat.

3. Tinjau dan daftar

Semua batch maksimal 100 NFT. Periksa jumlah, rentang blok, token ID, alamat minter, dan hasil audit sebelum menekan tombol. Wallet akan meminta konfirmasi untuk setiap transaksi batch.

Menunggu kontrak owner dan file valid.

Tool ini hanya menyiapkan dan mengirim transaksi yang Anda tinjau lalu setujui sendiri di wallet. Kontrak akan menolak pendaftaran ID yang sudah pernah dicatat. Jika sebagian batch sudah berhasil, buat ulang file hanya untuk rentang blok baru sebelum melanjutkan.
