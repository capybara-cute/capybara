Aturan token (disetujui user 1 Nov 2026)

  • Token komunitas BEP20/ERC20, diberikan ke pembeli paid mint dan komunitas — bukan dijual. Tidak ada fungsi penjualan, tidak ada tax, tidak ada raised / target dana (raised max sudah dihapus user).
  • Total supply tetap: 100.000.000 token, dicetak sekali ke wallet deployer saat deploy, tidak bisa dicetak lagi.
  • Pembagian yang disetujui: 50% pembeli paid mint (dibagi rata per NFT paid saat snapshot; kalau semua 5.000 paid laku = 10.000 token per NFT paid), 30% komunitas, 20% cadangan likuiditas/ekosistem. Pembagian dilakukan owner lewat transfer biasa setelah deploy, dengan tx hash dipublikasikan — kontrak ini tidak punya fungsi distribusi otomatis.
  • PERINGATAN SIMBOL: kontrak NFT Cappybara yang sudah live sudah memakai simbol CAPY di BNB Chain. Kalau token ini juga memakai CAPY, wallet/explorer bisa membingungkan keduanya. Pertimbangkan simbol CAPPY di Langkah 2 sebelum sign — setelah deploy tidak bisa diubah lagi.

2. Deploy Token

Nama dan simbol di bawah ini adalah nilai FINAL saat deploy. Ubah dulu sebelum sign kalau perlu (misalnya simbol CAPY menjadi CAPPY).

Total supply: 100.000.000 token, 18 desimal, ke wallet deployer.

3. Cek Kontrak Setelah Deploy

Bandingkan dengan yang diharapkan: name = nama di Langkah 2, symbol = simbol di Langkah 2, decimals = 18, totalSupply = 100000000000000000000000000 (100.000.000 × 10^18), balanceOf(deployer) = totalSupply sesaat setelah deploy (sebelum distribusi).

4. Setelah Deploy — Distribusi (manual, oleh owner)

  1. Transfer 50.000.000 ke pembeli paid mint sesuai snapshot, 30.000.000 ke komunitas, 20.000.000 ke cadangan — lewat transfer biasa dari wallet deployer.
  2. Publikasikan semua tx hash distribusi supaya bisa dicek publik.
  3. Baru umumkan alamat token di web / share kit setelah deploy + distribusi pertama selesai. Jangan umumkan alamat sebelum deploy.
